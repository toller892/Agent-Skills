## 模型说明

### Paraformer ⭐ 推荐
阿里 FunASR 开源模型，专为中文优化。支持自动说话人识别（使用 cam++ 模型），能将会议录音自动分段为不同说话人的发言。在测试中识别出 **179 段发言**，分段最精细，准确率 94%，完全免费，适合多人会议转录场景。

**实测效果**：
- 发言段落：179 段（最精细）
- 说话人标识：说话人 0, 1, 2, 3, 4
- 转录速度：~3 分钟
- 输出文件：15KB

**最适合**：需要区分说话人的多人会议（推荐）

### SenseVoice
阿里开源的多语言语音识别模型，支持 50+ 语言。准确率最高（95%），转录速度最快（~30秒），但不支持说话人识别，所有内容会合并为一段。适合单人演讲、播客等场景。

**实测效果**：
- 发言段落：1 段（无分段）
- 说话人标识：说话人 A（统一标识）
- 转录速度：~30 秒（最快）
- 输出文件：6.2KB

**最适合**：单人演讲或不需要区分说话人的场景

### Gemini 2.5 Flash
Google 最新的多模态 AI 模型，支持直接处理音频文件。能够识别说话人（标注为说话人 1, 2, 3...），在测试中识别出 **126 段发言**，转录速度快（~10-30秒），支持 100+ 语言。免费配额有限，需要网络连接。准确率约 90%，在某些专业术语上可能有误识别。

**实测效果**：
- 发言段落：126 段（良好）
- 说话人标识：说话人 1, 2, 3...
- 转录速度：~10-30 秒（很快）
- 输出文件：8.8KB
- 输出格式：标准 Markdown

**最适合**：需要快速转录且有 API 配额的场景

### AssemblyAI
云端 API 服务，零配置即可使用。支持说话人识别，但准确率相对较低（87%），且需要付费（$0.25/小时）。适合快速原型开发或不想配置本地环境的场景。

**最适合**：快速开始，无需本地配置

## 实际转录质量对比

### 相同片段对比（开场部分）

**Paraformer（179段）**：
```markdown
### [00:05] 说话人 0
咱们开始吧，

### [00:09] 说话人 1
哦且还是吧，

### [00:16] 说话人 2
这个吃不去。
```

**Gemini（126段）**：
```markdown
### [00:00] 说话人 1
我们开始吧。

### [00:00] 说话人 1
二句开始吧。

### [00:00] 说话人 2
嗯。
```

**SenseVoice（1段）**：
```markdown
### [00:00] 说话人 A
我们开始吧。 抱且还喜欢。 这吃不。 是。 嗯，第一个是嗯如口这边...
```

**分析**：
- **Paraformer**：分段最精细，每句话独立，时间戳准确
- **Gemini**：分段良好，但时间戳不够精确（都显示 00:00）
- **SenseVoice**：无分段，所有内容连续

## 推荐

**会议转录（免费）** → **Paraformer** ⭐（免费 + 最精细分段 + 高准确率 + 离线）

**会议转录（有配额）** → **Gemini 2.5 Flash**（快速 + 良好分段 + 零配置）

**单人演讲** → **SenseVoice**（最高准确率 + 最快速度）

**快速测试** → **AssemblyAI**（零配置，立即开始）
